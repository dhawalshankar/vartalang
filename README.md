# VartaLang 🌉
## India's Language Bridge for Real Economic Opportunity

VartaLang is a language-exchange, practical-learning, and vernacular-jobs
platform designed around measurable economic outcomes rather than passive
content consumption. This repository contains the production web application
for `vartalang.in`.

---

## 🎯 **The Reality**

### India Has a Language Problem
- **1.5 billion people** speaking 22 official languages and hundreds of dialects
- **400+ million workers** in informal economy—artisans, craftspeople, vendors, small businesses
- **Language is barrier #1** stopping people from expanding their income across state lines
- A Kerala artisan can't sell to Delhi because they don't speak Hindi
- A Bengali vendor can't work in Mumbai because they don't speak Marathi  
- A Tamil craftsperson can't access Gujarati markets because of language

### What Doesn't Work
❌ **Duolingo/Babbel**: Teach you how to order coffee, not how to negotiate wholesale prices  
❌ **Expensive Tutors**: ₹1,500-3,000 per hour—unaffordable for 95% of India  
❌ **LinkedIn**: Only helps English-speaking office workers  
❌ **YouTube**: Random videos with no practice partners or community  

### The Gap
**There is NO platform that helps regular Indians learn the language they need to do business in the market they want to access.**

## 🏗️ Production architecture

VartaLang is deployed as independently operated services rather than a single
monolith:

| Surface | Responsibility | Deployment |
|---|---|---|
| Main web application | Profiles, matching, chat, jobs, and community UX | Vercel |
| Main API | Authentication, matching, jobs, notifications, and Socket.IO | Render |
| LMS web application | Courses, practice, progress, and checkout UX | Vercel |
| LMS API | Course, enrollment, payment, and progress domain | Render |
| Challenge execution | Serverless challenge functionality | Vercel |

The services communicate through authenticated HTTP APIs and domain boundaries.
This keeps the main platform's MongoDB data model separate from the LMS
PostgreSQL data model while allowing the products to participate in one
VartaLang ecosystem.

## 🚀 Production ecosystem

The VartaLang web application is deployed on Vercel at
`https://vartalang.in`. It is connected to the independently deployed
Node.js/Express backend and Socket.IO service described in this repository's
backend project. The VartaLang LMS is a separate Next.js application at
`https://learn.vartalang.in`, backed by an independent FastAPI/PostgreSQL
service.

The platform ecosystem also includes serverless challenge functionality on
Vercel and Google Cloud integrations used by the LMS for YouTube Data API v3
playlist-based course importing. These services are separated by domain and
deployment boundary while participating in the same VartaLang product
ecosystem.
